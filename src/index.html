What gets synced

  • 🖥️ Tab bar position, toolbar layout, address bar
  • 🎨 Themes and appearance
  • ⌨️ Keyboard shortcuts and command chains
  • 🔍 Default search engine
  • 🧩 Browser extensions (copy between profiles)
  • 📌 Web panels, workspaces, startup settings
